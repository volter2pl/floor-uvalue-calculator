# Floor U-value Calculator

Proste narzędzie do szybkiego szacowania współczynnika przenikania ciepła (U) dla podłóg na gruncie. Wystarczy podać najważniejsze parametry przegród i izolacji, a aplikacja natychmiast pokaże wynik oraz najważniejsze dane pośrednie.

👉 [Przetestuj wersję online](https://volter2pl.github.io/floor-uvalue-calculator/)

### Najważniejsze funkcje
- dynamiczne przeliczanie wartości U w miarę wprowadzania danych,
- prezentacja najważniejszych parametrów cieplnych w jednym miejscu,
- intuicyjny interfejs stworzony z myślą o szybkiej pracy projektanta lub audytora energetycznego.
